## Music-Store-Analysis-SQL-Project
## Project Overview
This project is a beginner-level SQL project created using the Chinook Music Store Database.
The primary objective of this project was to practice and strengthen fundamental SQL concepts by solving real-world business questions related to customers, sales, artists, albums, tracks, and genres.
Through this project, I explored the database, analyzed sales data, and generated business insights using SQL queries.

## Objectives
- Understand relational database structure
- Practice writing SQL queries
- Explore and analyze sales data
- Improve problem-solving skills using SQL
- Build a portfolio project for Data Analytics

## Tools Used
- MySQL Workbench 8.0 CE
- MySQL
- Chinook Music Store Database

## Business Questions Solved
# Basic Analysis
- Which countries have customers?
- Who are the top 10 customers by spending?
- What is the average invoice value?
- Country generating most orders/Invoices?
- What are top 3 values of total invoice?
- Which city has the best customers?
- Who is the best customer? 

# Intermediate Analysis
- Best Selling Genres
- Most Purchased Tracks
- Top Selling Albums
- Revenue By Country
- Identified Rock Music listeners
- Ranked the top 10 Rock artists by track count
- Analyzed tracks longer than the average song length.

# Advanced Analysis
- Which Artist Earned Most Revenue?
- Genre Preference By Country
- How much amount spent by each customer on artists?

## Key Insights
- Rock is the best selling genre across the store.
- USA generates the highest revenue.
- Certain countries show strong preferences for specific music genres.
- A limited number of artists account for a large share of total sales.
- Revenue distribution varies significantly across countries.
